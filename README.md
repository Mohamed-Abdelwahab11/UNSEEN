# UNSEEN

AI-driven counterfactual modeling of media coverage to detect statistically unexpected omissions and underreported real-world events.

## Overview

UNSEEN models expected media coverage probabilities to identify statistically anomalous omissions of important events without making subjective claims of bias.

## Quickstart

```bash
git clone https://github.com/Mohamed-Abdelwahab11/UNSEEN.git
cd UNSEEN
pip install -r requirements.txt
```
